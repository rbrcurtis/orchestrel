# Orchestrel Desktop

Two Electron desktop wrappers:

- `Orchestrel` opens `https://orchestrel.com/`
- `Orc Chat` opens `https://orchestrel.com/chat/19/`

## Development

```sh
npm install
npm run start:orchestrel
npm run start:orc-chat
```

## Packaging

```sh
npm run build
```

Individual builds:

```sh
npm run build:orchestrel
npm run build:orc-chat
```
